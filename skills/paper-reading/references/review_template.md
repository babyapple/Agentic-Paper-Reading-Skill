# Review Template / 报告模板

写报告时读本文件。结构化的机器记录见 `paper_schema.md`，两者必须互相一致。

## 使用方式

1. 按 `SKILL.md` 的阅读流程读论文，并先定 `paper_type`（`empirical` / `humanities` / `survey`）。
2. 按下面的骨架逐节填；缺信息与不编造这两条规则见 `SKILL.md` 的"必须守住的几条"。

## 篇幅约定

- 单篇报告正文控制在 600–1200 字。
- 每节 1–4 句。`Limitations` 与 `extensions` 要写到具体处；写不出具体内容就不要用空话凑数。
- 用户明确要求详细时逐节展开，但不要靠重复原文凑长度。

## 骨架

```markdown
# <论文标题>

- 类型：empirical / humanities / survey
- 出处：<期刊 / 会议 / 单位>，<年份>
- 一句话结论：<作者最想让你相信的那句话>

## 1. 研究问题 Research Problem
## 2. 研究动机 Motivation
## 3. 核心观点 Main Idea / Core Claim
## 4. 方法或论证路径 Method / Argument
## 5. 材料与证据 Materials & Evidence
## 6. 主要结果 Main Results / Findings
## 7. 支撑性分析 Supporting Analysis
## 8. 优势与贡献 Strengths
## 9. 局限 Limitations
## 10. 可能的延伸 Possible Extensions

---
阅读范围：第 X–Y 页，共调用工具 N 次
未解决的问题：<gaps>
```

## 逐节写法

### 1. 研究问题 Research Problem

用一句话说清"它在解决什么"。**不要**抄摘要原句。
自检：把这句话单独拿给别人看，他知道这篇论文要干什么吗？

> 例（人文类）：以第十四届"荷花奖"现代舞参评作品为对象，讨论"概念性"如何在中国现代舞中被转化为可被观看的空间实践。

### 2. 研究动机 Motivation

为什么这个问题值得研究：既有研究留下了什么空白、现实中有何困扰。
作者没有明说动机就写"论文未明确说明动机"，不要替作者编。

### 3. 核心观点 Main Idea / Core Claim

作者最想让你相信的那一句，写成可被证伪、可被反驳的陈述句。
有多个并列主张时逐条列出，并标注哪一条是主线。

### 4. 方法或论证路径 Method / Argument

- `empirical`：模型 / 算法 / 实验设计，自变量是什么、因变量是什么。
- `humanities`：论证分几层推进、每层靠什么材料支撑。
- `survey`：分类框架怎么划的、依据是什么。

### 5. 材料与证据 Materials & Evidence

- `empirical`：数据集、规模、baseline、评价指标。
- `humanities`：史料、文本、作品、田野材料，以及作者怎么筛选与处理它们。
- `survey`：纳入标准、覆盖范围。

评审要点：**这些材料够不够支撑第 3 节那个主张？** 把判断写进来。

### 6. 主要结果 Main Results / Findings

- 有数字的：给数字并标页码，如"准确率 78.3%，优于最强 baseline 4.1 个百分点 [p.9]"。
- 无数字的（人文类常见）：写作者得出了什么结论，以及支撑它的关键材料。

**不要**把作者的结论改写成更强的说法。

### 7. 支撑性分析 Supporting Analysis

- `empirical`：消融、稳健性、失败案例分析。没有就写"论文未做消融分析"。
- `humanities`：对反例、边界情况、竞争性解释的处理。
- `survey`：对争议问题的呈现是否平衡。

这一节是判断"证据是否充分"的主要依据，不要跳过。

### 8. 优势与贡献 Strengths

写**你的**判断，不是复述作者自评。每条尽量落到具体处：哪个设计聪明、哪个材料难得、哪个分析扎实。

### 9. 局限 Limitations

分开写两组：**作者承认的**局限，以及**你发现的**局限（要说明依据）。
常见记录点：材料代表性不足、缺少消融或对照、结论超出证据、概念界定模糊、外部效度问题。

### 10. 可能的延伸 Possible Extensions

要具体可做：换什么材料、加什么对照、补什么分析。不要写"未来可以进一步研究"这类空话。

## 反例（不要这样写）

| 错误写法 | 问题 |
| --- | --- |
| "本文提出了一种创新方法，效果显著。" | 无页码、无数字、无具体内容，等于没说 |
| "实验表明该方法在所有数据集上都最优。" | 夸大了作者的结论 |
| "作者没有做消融，说明方法不扎实。" | 越界：缺消融是局限，不是"不扎实"的证明 |
| "该文对舞蹈研究具有重要价值。" | 空泛，没有落到具体贡献 |
| 通篇复述摘要 | 没有做第 6 步的"结论 ↔ 证据"核对 |

## 交付前自检

- [ ] 10 个部分都有内容，或明确写了"论文未涉及"
- [ ] 具体事实都有页码，或明确标注"未找到依据"
- [ ] 论文类型判断正确（没有向人文论文要消融实验）
- [ ] `Strengths` / `Limitations` 是判断而非复述
- [ ] 陈述与解释在文字上分得开
- [ ] 与 `paper_schema.md` 的记录一致
